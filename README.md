## ✦ Featured Projects

### StudyVault

A full-stack resource management platform built with the MERN stack.

It includes authentication, dashboards, resource management, CRUD operations, categories, search, and filtering.

**Tech:** React.js · Node.js · Express.js · MongoDB · Tailwind CSS

---

### MealWise

A meal discovery and planning application using **TheMealDB API**, designed to make exploring and saving meals simple and interactive.

Features include favorites, dark mode, API-based meal discovery, and animated interactions.

**Tech:** React.js · Tailwind CSS · Framer Motion · REST API

---

### Quiz App

A browser-based quiz application built during my early web development journey.

It was one of the projects that helped me strengthen my understanding of JavaScript, user interaction, and frontend fundamentals.

**Tech:** HTML · CSS · JavaScript

## ✦ The Portfolio

The portfolio itself was built with **React and Tailwind CSS**, with a visual direction inspired by editorial layouts, personal journals, and the feeling of collecting little moments.

Some of the details include:

* GSAP & ScrollTrigger animations
* Lenis smooth scrolling
* Interactive project cards
* Micro-interactions
* Editorial-inspired typography
* Personal photography
* Creative sections beyond development
* A small visitor interaction called **Little Trace**

The goal was to keep the experience **clean, personal, and intentional** rather than making it feel like a typical developer template.

## ✦ A Little Trace

**Little Trace** is a small interactive guestbook-style experience where visitors can leave a thought or message behind.

The messages are stored using **Supabase**, giving this interaction a real backend and persistent data storage.

It is inspired by the idea that even a short visit can leave a small trace.
